# 한계와 재현성

- 민원 건수는 고객 수, 거래량, 시장점유율로 표준화하지 않았으므로 회사의 품질과 성과를 순위화할 수 없다.
- CFPB 공개 자료의 신고/처리 지연, 자가보고 범주가 결과에 영향을 준다. 2026-08-14 이후 신규 서술문 공개가 중단되어 텍스트 분석은 정책 변경 전 역사 자료에 한정한다.
- 최근 두 달 제외는 완전 월 비교를 위한 일반 규칙이며, 수집 지연이 더 길면 조정이 필요하다.
- 이상치는 조사 후보일 뿐 원인, 규제 위반, 자동 컴플라이언스 판단이 아니다.
- 실행일, snapshot date, row cap, cutoff, 품질 집계는 CSV와 `quality_table.csv`에 남긴다. 동일한 raw snapshot과 Python 의존성을 사용하면 결과를 재생성할 수 있다.
