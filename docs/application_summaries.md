# 지원용 요약

**이력서 1문장**: CFPB 민원 데이터를 DuckDB·Python·Power BI용 스타 스키마로 재현 가능하게 구축하고, 불완전월 제외·이상치·응답 KPI·텍스트 주제 분석을 구현했습니다.

**포트폴리오 소개**: 원본-스테이징-마트-BI 계층과 SQL/Python 대조를 포함해, 공개 민원 데이터를 운영 검토 우선순위로 전환했습니다. 고객 수 분모가 없는 회사 품질 순위는 의도적으로 배제했습니다.

**면접 도입**: 데이터 품질과 해석 경계를 먼저 설계했습니다. 특히 taxonomy 버전, 불완전월, 적기응답 분모를 코드와 문서 양쪽에 명시해 숫자의 과잉 해석을 줄였습니다.
