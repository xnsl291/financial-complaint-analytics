# 면접 Q&A

**왜 회사 랭킹을 하지 않았나요?** 고객 수나 시장점유율 분모가 없어서 민원 수만으로 품질을 비교하면 잘못된 결론이 됩니다. 이 프로젝트는 product/issue 운영 검토 우선순위에 한정했습니다.

**최근 데이터를 왜 제외하나요?** 불완전 월은 접수·공개 지연 때문에 추세를 왜곡할 수 있습니다. 실행일에서 두 달 전 말일을 동적으로 cutoff로 씁니다.

**이상치는 어떻게 설명하나요?** 최소 건수 뒤 3개월 비교 baseline의 median/MAD robust z-score를 사용합니다. 이후에도 기준 이상이면 persistent, 아니면 spike입니다.

**텍스트 분석의 경계는?** 영어 TF-IDF와 1~2-gram으로 반복 주제를 보여 줄 뿐, LLM이나 자동 판단으로 규정 위반을 판정하지 않습니다.

**SQL과 Python 결과가 다르면?** demo 파이프라인은 DuckDB fact count와 Python 정규화 건수를 비교해 실패 신호로 사용합니다. 집계 정의·중복키·필터 cutoff를 먼저 대조합니다.
