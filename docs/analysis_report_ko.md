# 금융소비자 민원·운영 리스크 분석 보고서

## 1. 의사결정 질문

분석 목적은 금융상품과 이슈별 민원 추세, 회사 대응 결과를 결합해 운영 및 내부통제 검토 순서를 정하는 것이다. 과거 공개 서술문은 원인 탐색을 돕는 보조 자료로만 사용한다. 고객 수나 시장점유율이 없기 때문에 회사를 품질 순으로 평가하지 않는다.

## 2. 데이터 범위와 완전 월

CFPB Consumer Complaint Database의 2023년 9월 이후 데이터를 대상으로 한다. 분석 시점의 최근 두 달은 공개·응답 지연 가능성이 있어 추세와 이상징후 판단에서 제외한다. CFPB가 안내한 2023년 8월 분류 변경 월을 메타데이터로 남겨 명칭 변경을 실제 증가로 오인하지 않도록 한다.

현재 실행환경에서는 CFPB API와 bulk 파일 서버가 HTTP 403을 반환했다. 따라서 실제 민원 수치에 관한 결론을 만들지 않았으며, 아래 결과는 245행 결정론적 데모 입력으로 파이프라인과 대시보드 동작을 검증한 값이다.

## 3. KPI와 데이터 품질

데모 스냅샷 2025-05-15에서 완전 월 마감은 2025-03-31이다. 원본 245행 중 중복 1행과 최근 불완전 월 99행을 제외해 145건이 분석 대상이 됐다. 적시응답 분모는 Yes/No가 명확한 행만 포함한다. 회사 전달·응답 날짜가 없는 경우 소요일 분모에서 제외한다.

## 4. 이상징후와 우선순위

상품×이슈별 최근 3개 완전 월의 중앙값과 MAD를 기준으로 robust z-score를 계산한다. 최소 민원 수 기준을 충족하지 않으면 급증으로 표시하지 않으며, 이후 두 달 중 높은 수준이 유지되면 `persistent`, 그렇지 않으면 `spike`로 구분한다.

검증용 데모에서는 Mortgage/Payment trouble과 Crypto asset/Fraud 두 조합이 spike로 탐지됐다. 이는 알고리즘 검증용 합성 패턴이며 실제 시장 신호가 아니다. 우선순위 점수는 규모 0.30, 증가율 0.25, 비적시 응답 0.20, 구제조치 0.15, 지속성 0.10을 기본값으로 사용한다. 점수는 조사 순서일 뿐 규제 위반 판정이 아니다.

## 5. VOC 텍스트 분석

공개 동의된 historical narrative만 사용한다. CFPB는 2026-08-14부터 신규 민원 서술문 공개를 중단했으므로 정책 변경 이후의 키워드 추세는 산출하지 않는다. 영어 소문자·불용어 정리 후 1~2 gram TF-IDF를 계산하고 최소 문서빈도를 적용한다. LLM이나 자동 컴플라이언스 판단은 사용하지 않는다. 실제 데이터 적용 시 상위 키워드 표본을 사람이 검토하고 상품·이슈 코드와 함께 해석한다.

## 6. Power BI 전달 구조

민원 1건 단위 fact와 날짜·상품·회사 차원을 단방향 1:*로 연결한다. 네 페이지는 경영 KPI, 월별 추세, 상품·이슈 운영 검토, VOC·품질로 구성한다. What-if 매개변수는 우선순위 가중치 합계가 1인지 확인하는 경고를 포함한다.

## 7. 실제 데이터 적용 시 업무 제안

- 증가 규모와 증가율이 동시에 높은 상품·이슈를 1차 검토 대상으로 둔다.
- 민원 증가와 비적시 응답이 함께 나타나는 영역에 처리 인력을 우선 배치한다.
- 정책 변경 전 역사 자료의 급증 키워드를 표본 검토해 안내문·상담 스크립트·프로세스 변경 후보를 만든다.
- 회사 비교에는 고객 수·거래량·시장점유율을 추가한 뒤 사용한다.

## 8. 한계

민원은 소비자 경험 전체를 대표하는 통계 표본이 아니다. 공개 동의 여부, 회사 규모, 상품 이용자 수, 분류 변경, 최근 공개 지연이 결과에 영향을 준다. 실데이터 실행 전에는 이 보고서의 데모 수치를 지원서 성과로 사용하지 않는다.
